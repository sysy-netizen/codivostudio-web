Codivo Studio 웹사이트 - 어떻게 만들어졌는지 쉽게 설명
================================================================

이 문서는 개발 지식이 없어도 이해할 수 있도록,
이 웹사이트가 어떤 구조로 동작하는지 쉬운 말로 설명합니다.


[1] 이 웹사이트는 무엇인가
------------------------------------------------
Codivo Studio는 "Seller Tools"라는 이름의 여러 프로그램(도구)을
한 사이트 안에서 사용할 수 있게 모아둔 플랫폼입니다.

- Rank Tracker (랭킹추적기)
- Keyword Analysis (키워드분석)
- Excel Converter (엑셀변환기)
- Price Calculator (가격계산기, 준비중)

여기에 블로그, 소개 페이지 등 일반 홈페이지 기능도 같이 있습니다.


[2] 어떤 기술로 만들어졌나 (Astro)
------------------------------------------------
이 사이트는 "Astro"라는 도구로 만든 정적 사이트입니다.

정적 사이트란: 사용자가 접속할 때마다 서버가 실시간으로 페이지를
새로 만드는 게 아니라, 미리 완성된 HTML 파일들을 그대로 보여주는
방식입니다. 그래서:
  - 로딩 속도가 빠름 (검색엔진 노출/애드센스에 유리)
  - 서버 유지비가 거의 안 듦 (Cloudflare Pages에 무료로 올릴 수 있음)

예전에는 워드프레스(WordPress) 방식을 검토했지만, 이 사이트의
목적(속도, 무료 운영, 애드센스)에는 Astro 정적 사이트가 더 맞아서
워드프레스는 쓰지 않기로 했습니다.


[3] 페이지 주소(URL)가 정해지는 방식
------------------------------------------------
Astro는 "폴더 구조 = 실제 웹주소" 방식을 씁니다.

예)
  src/pages/index.astro                    → codivostudio.com/
  src/pages/tools/index.astro               → codivostudio.com/tools/
  src/pages/tools/rank-tracker/index.astro  → codivostudio.com/tools/rank-tracker/
  src/pages/blog/index.astro                → codivostudio.com/blog/

즉 새 폴더/파일을 만들면 그게 곧 새로운 페이지 주소가 됩니다.


[4] 모든 페이지가 공유하는 공통 틀 (Layout)
------------------------------------------------
페이지마다 header, footer를 매번 새로 만들지 않고, "레이아웃"이라는
공통 틀 안에 내용만 끼워 넣는 방식입니다.

- BaseLayout.astro
    모든 페이지가 공통으로 쓰는 기본 틀. 상단 Header, 하단 Footer,
    사이트 전체 색상/폰트 등이 여기 정의되어 있습니다.

- ProgramLayout.astro
    Seller Tools 프로그램 페이지 전용 틀. 제목/설명/관련 글 링크
    같은 반복되는 형태를 자동으로 만들어줍니다.

- Header.astro / Footer.astro
    사이트 상단/하단 메뉴. 한 곳만 고치면 모든 페이지에 반영됩니다.


[5] 프로그램(도구) 메뉴는 한 곳에서 관리
------------------------------------------------
src/data/programs.ts 파일 하나에 "어떤 프로그램이 있고, 주소가
어디인지"가 목록으로 정리되어 있습니다.

새 프로그램을 추가하고 싶으면, 이 목록에 한 줄만 추가하면
메뉴에 자동으로 나타나는 구조입니다. (Header 코드를 직접 고칠
필요 없음)

프로그램마다 연결 방식이 다릅니다:
  - Rank Tracker / Keyword Analysis
      → 다른 곳에 이미 만들어진 프로그램을 화면 안에 그대로
        가져와서 보여주는 방식(iframe)
  - Excel Converter
      → 외부의 실제 프로그램 주소로 바로 이동(링크)하는 방식
        (Streamlit이라는 별도 기술로 만들어져 있어서, 이 사이트
        안에 직접 넣지 않고 새 화면/새 창으로 연결만 함)


[6] 블로그 글은 어떻게 관리되나
------------------------------------------------
블로그 글은 src/content/blog 폴더 안에 마크다운(.md) 파일로
하나씩 저장되어 있습니다. 파일 하나 = 글 하나 입니다.
새 글을 쓰려면 이 폴더에 파일을 추가하면 됩니다.


[7] "완성"부터 "실제로 보이기까지" (빌드 → 배포)
------------------------------------------------
코드를 고친다고 바로 실제 사이트(codivostudio.com)에 반영되는
것은 아닙니다. 아래 순서를 거칩니다.

1) 코드 수정
   src/ 폴더 안의 파일들을 고칩니다. (지금까지 해온 작업)

2) 빌드 (build)
   "npm run build" 명령을 실행하면, Astro가 수정한 코드를
   실제 웹브라우저가 읽을 수 있는 HTML/CSS/JS 파일들로
   변환해서 dist 라는 폴더에 만들어 냅니다.
   (이 단계까지는 내 컴퓨터 안에서만 일어나는 일입니다)

3) 배포 (deploy)
   dist 폴더의 결과물을 Cloudflare Pages라는 무료 호스팅
   서비스에 올려야, 비로소 전 세계 누구나 codivostudio.com
   주소로 접속했을 때 바뀐 내용을 볼 수 있습니다.

정리하면:
   코드 수정 → (빌드) → (배포) → 실제 사이트에 반영됨

빌드까지는 자동으로 확인할 수 있지만, "배포"는 Cloudflare
계정 로그인이 필요한 별도 단계라 상황에 따라 직접 진행하셔야
할 수도 있습니다.


[8] 요약
------------------------------------------------
- Astro로 만든 "정적 사이트" (빠르고, 호스팅비 무료)
- 폴더 구조 그대로 웹주소가 됨
- Header/Footer/레이아웃은 공통으로 재사용
- 프로그램 목록은 programs.ts 한 곳에서 관리
- 블로그 글은 마크다운 파일 하나하나로 관리
- 코드 수정 → 빌드 → 배포, 이 세 단계를 거쳐야 실제 사이트에 반영됨
