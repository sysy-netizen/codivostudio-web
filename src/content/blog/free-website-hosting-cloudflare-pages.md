이 사이트(codivostudio.com)는 지금 도메인 등록비 말고는 운영비가 들지 않습니다. 호스팅비, SSL 인증서 비용 모두 0원입니다. 워드프레스였다면 PHP·MySQL이 돌아가는 유료 호스팅이 필요했겠지만, 정적 사이트(Astro)와 Cloudflare Pages 조합으로 옮기면서 이 비용이 사라졌습니다.

## 뭐가 무료이고, 뭐에 돈이 드는가

**무료**: Cloudflare Pages 호스팅, SSL 인증서 자동 발급, GitHub 저장소 연동 자동 배포.
**유료로 남는 것**: 도메인 등록비뿐입니다. 저희는 가비아에서 등록한 `codivostudio.com`을 그대로 유지하고, **네임서버만 Cloudflare로 옮겼습니다.** 도메인 자체를 옮기는 게 아니라, "이 도메인의 DNS를 어디서 관리할지"만 바꾸는 작업이라 등록 대행사를 갈아탈 필요는 없었습니다.

## 실제로 옮긴 순서

1. Cloudflare 계정을 만들고 도메인을 추가하면, Cloudflare가 지정하는 네임서버 주소 두 개를 알려줍니다.
2. 가비아 관리 화면에서 기존 네임서버를 Cloudflare가 알려준 값으로 바꿉니다.
3. 전파에는 시간이 걸립니다. 실제로 저희는 오후에 바꾼 뒤 국내 일부 통신사 DNS에는 저녁까지도 반영이 안 된 적이 있었습니다. `nslookup -type=NS 도메인주소`로 전파 여부를 직접 확인하며 기다렸습니다.
4. Cloudflare Pages 프로젝트를 만들고 GitHub 저장소를 연동하면, 이후로는 `main` 브랜치에 푸시할 때마다 자동으로 재배포됩니다.

## 놓치기 쉬운 부분

네임서버를 옮기면 기존에 쓰던 메일 관련 레코드(MX, SPF/TXT)도 같이 옮겨줘야 메일이 끊기지 않습니다. 저희는 기존 메일 서비스의 MX/TXT 레코드를 그대로 Cloudflare DNS에 옮겨서 이 부분은 문제없이 넘어갔습니다.

반대로 놓쳤던 부분도 있었습니다. 이미 다른 서비스(Vercel)에 배포해둔 서브도메인(`tools.codivostudio.com`)의 CNAME 레코드가 Cloudflare의 자동 스캔 목록에서 빠져 있었습니다. 도메인을 옮길 때 기존 DNS 레코드를 자동으로 가져와주는 기능이 있긴 하지만, 100% 완벽하게 다 긁어오는 건 아니라는 걸 이때 알았습니다. 서브도메인을 따로 쓰고 있다면 이전 후에 꼭 하나하나 확인하는 걸 권합니다.

## 정리

- 정적 사이트 + Cloudflare Pages 조합이면 호스팅·SSL 비용 없이 운영 가능, 도메인 등록비만 남음
- 네임서버 이전은 도메인 자체 이전이 아니라 DNS 관리 주체만 바꾸는 작업
- 메일 레코드(MX/TXT)는 반드시 함께 옮겨야 하고, 서브도메인 레코드는 자동 스캔에서 빠질 수 있어 직접 확인이 필요
